# External bound compilations

Literature constraints used for the comparison figures of notebook 04, copied unchanged (MIT licenses included):

- `PBHbounds/`: constraints on the PBH dark-matter fraction f_PBH(M) from Bradley J. Kavanagh's
  [PBHbounds](https://github.com/bradkav/PBHbounds) (commit in `SOURCE_COMMIT`). Envelopes of microlensing,
  accretion and dynamical bounds, the LIGO merger-rate bound, and the projected GW-lensing bound; see each
  file's header and the PBHbounds README for the original references.
- `AxionLimits/BlackHoleSpins_noSI.txt`: black-hole superradiance windows on the axion mass, without
  self-interactions (arXiv:2009.07206), from Ciaran O'Hare's [AxionLimits](https://github.com/cajohare/AxionLimits).
